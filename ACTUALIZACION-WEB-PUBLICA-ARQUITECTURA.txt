DESPLIEGUE EN GITHUB PAGES
1. Copiar todo el contenido del ZIP en Documentos/GitHub/Santuario-Winston-Web.
2. Reemplazar archivos cuando Windows lo pregunte.
3. Commit y Push origin desde GitHub Desktop.
4. GitHub Pages seguirá en modo staging/noindex de forma intencionada.

IMPORTANTE PARA EL DOMINIO FINAL
Antes de migrar a santuariowinston.com hay que ejecutar el build en modo producción o retirar la protección de staging. No publicar el dominio definitivo con Disallow: / ni noindex.
